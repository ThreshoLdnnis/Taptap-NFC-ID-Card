03 / HOW IT WORKS

预印好的卡，
写入你自己的故事。

卡面由商家统一印制。拿到可写 NFC 卡后，重点是做好公开可访问的个人主页，再将链接写入并实机测试。

01 /

选择数字主页路线

按兴趣制作页面；网址是写进卡片的数据，页面内容可以继续更新。

Canva / Notion 无代码主页GitHub Pages 自建主页vCard 联系人备选
02 /

把网址写入卡片

在 NFC Tools 中添加 URL / URI 记录，将公开链接写入可写卡片。暂不锁定，方便后续换绑。

03 /

现场碰卡互测

用不同手机测试页面能否正常打开；vCard 联系人路线需要额外检查设备兼容性。
